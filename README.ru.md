# Floatland Lite — 0.7.0-lite3

Первая тестовая версия ветки `lite`. Старая main пока остаётся стабильной версией.

Floatland работает самостоятельно, без будущего shell. Вместо широкой полосы заголовка — капсула с кнопками и ручкой перемещения. В свёрнутом виде она оставляет маленький индикатор; наведение раскрывает управление, ПКМ открывает меню окна. Перемещение начинается только за ручку.

Сохранены floating/tiling, память геометрии, snap и палитра, Always on top, All workspaces, Lua-настройки и правила. Alt+Tab использует иконки. Super+G открывает компактную панель превью справа, не скрывая остальные окна.

GTK/Qt/Ozone-интеграции удалены. Убраны перехваты renderWindow/renderFadeouts и подавление обычных окон в overview. Захват превью по-прежнему использует native-плагин и зависит от версии Hyprland.

## Запуск

Останови старую сессию Floatland, распакуй архив и запусти из его папки:

```sh
python3 run.py
```

Сборка плагина и запуск демона выполняются вместе. Требования: Linux и Hyprland 0.56.2 с соответствующими заголовками; полный список зависимостей в [README.md](README.md).

Настройки создаются отдельно: `~/.config/floatland-lite/`. Менять нужно файлы там, а не шаблоны в исходниках. После правок: `python3 run.py reload`. Лог: `logs/session.log`. Остановка: Ctrl+C или `python3 run.py stop`.

Если ранее включались глобальные launcher overrides для нативных интеграций, отключи их через старую установку до её удаления.

Это тестовый выпуск: логические проверки доступны через `python3 tools/check.py`, но полная сборка плагина и визуальная работа на Linux ещё требуют проверки. Здесь не обещается уже подтверждённая стабильность старой ветки.
